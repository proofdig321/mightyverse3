### Upload Flow
1. **Client**: Initiates TUS upload via upload service
2. **TUS Endpoint**: Creates Livepeer asset with proper configuration
3. **Livepeer**: Processes video and exports to IPFS
4. **Database**: Stores asset metadata with IPFS CID
5. **Frontend**: Displays processed asset with 2.5D capabilities

## 2.5D Holographic Architecture

### Layer Structure
```typescript
interface HolographicLayers {
  background: string;    // Background layer URL
  midground: string;     // Midground layer URL  
  foreground: string;    // Foreground layer URL
  depthMap: string;      // Depth map for 3D effects
}
```

### Rendering Pipeline
1. **Layer Loading**: Parallel loading of all layer assets
2. **Depth Processing**: Apply depth map for 3D positioning
3. **Parallax Calculation**: Dynamic layer movement based on interaction
4. **Canvas Composition**: Real-time layer blending and effects
5. **Interactive Response**: Mouse/touch interaction handling

### HeroCanvas Features
- **Multi-layer support**: Background, midground, foreground
- **Depth effects**: Z-axis positioning and parallax
- **Interactive elements**: Mouse tracking and response
- **Performance optimized**: Efficient canvas rendering
- **Responsive design**: Adapts to different screen sizes

## Troubleshooting Guide

### Common Issues
1. **Layer Loading Failures**: Check IPFS connectivity and asset URLs
2. **Canvas Performance**: Reduce layer resolution or enable hardware acceleration
3. **Upload Errors**: Verify Livepeer API key and TUS endpoint configuration
4. **Conversion Failures**: Ensure source video is accessible and properly formatted
